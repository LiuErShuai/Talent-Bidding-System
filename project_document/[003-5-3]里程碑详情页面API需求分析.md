## 页面需要的信息

**组件**：`src/components/enterprise/MilestoneDetail.vue`

**需要展示**：
1. 里程碑基本信息：标题、描述、状态、计划日期
2. ~~交付物要求列表：名称、支持格式、具体要求~~（【V2.0功能】当前版本暂不实现）
3. 任务文件列表：企业上传的参考资料
4. 承接方提交记录：所有版本的提交文件、审核状态、审核意见
5. ~~意见反馈列表：企业给出的修改建议~~（【V2.0功能】当前版本暂不实现）

## 需要补充字段的API

### GET /api/v1/milestone/{milestoneId}

**原始API返回**：只有 `deliverableUrl`（单个URL）

**缺少字段**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `deliverables` | Array | 交付物要求列表（【V2.0功能】当前版本暂不实现） |
| `taskFiles` | Array | 任务文件列表 |
| `submissions` | Array | 提交记录列表 |
| `feedbacks` | Array | 意见反馈列表（【V2.0功能】当前版本暂不实现） |

## 需要补充的API

### GET /api/v1/milestone/{milestoneId}/detail

**作用**：获取里程碑完整详细信息（基本信息+交付物+任务文件+提交记录+反馈）

**请求参数**：

| 参数名 | 位置 | 类型 | 必选 | 说明 |
|--------|------|------|------|------|
| milestoneId | path | String | 是 | 里程碑ID |
| Authorization | header | String | 是 | 认证token |

**返回字段**：

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `deliverables[].name` | String | 交付物名称 |
| `deliverables[].type` | String | 类型（document/archive/video/link） |
| `deliverables[].formats` | Array | 支持的文件格式 |
| `deliverables[].requirement` | String | 具体要求说明 |
| `taskFiles[].fileName` | String | 文件名 |
| `taskFiles[].fileUrl` | String | 文件下载URL |
| `taskFiles[].fileSize` | Integer | 文件大小（字节） |
| `taskFiles[].description` | String | 文件说明 |
| `submissions[].version` | Integer | 版本号 |
| `submissions[].versionNote` | String | 版本说明 |
| `submissions[].status` | String | 审核状态（pending/approved/rejected） |
| `submissions[].reviewResult` | Object | 审核结果 |
| `feedbacks[].content` | String | 反馈内容 |

### POST /api/v1/milestone/{milestoneId}/task_file

**作用**：企业上传任务文件（参考资料）

**请求参数**：

| 参数名 | 类型 | 必选 | 说明 |
|--------|------|------|------|
| fileName | String | 是 | 文件名 |
| fileUrl | String | 是 | 文件URL |
| fileSize | Integer | 是 | 文件大小（字节） |
| description | String | 否 | 文件说明 |

### GET /api/v1/milestone/{milestoneId}/submissions

**作用**：查询所有提交记录（包括历史版本）

**请求参数**：

| 参数名 | 类型 | 必选 | 说明 |
|--------|------|------|------|
| deliverableId | String | 否 | 按交付物筛选 |

**返回示例**：
```json
{
  "data": [
    {
      "submissionId": "s1",
      "deliverableId": "d1",
      "version": 2,
      "fileName": "技术方案-v2.pdf",
      "fileUrl": "https://...",
      "fileSize": 3251200,
      "uploadTime": "2025-11-18T14:30:00",
      "uploaderName": "张三",
      "versionNote": "补充了技术选型依据",
      "status": "approved",
      "reviewResult": {
        "reviewTime": "2025-11-18T16:00:00",
        "action": "approved",
        "comment": "方案完善",
        "rating": 5
      }
    }
  ]
}
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| `version` | 版本号（从1开始递增） |
| `versionNote` | 版本说明 |
| `status` | 审核状态（pending/approved/rejected） |
| `reviewResult` | 审核结果（如果已审核） |
