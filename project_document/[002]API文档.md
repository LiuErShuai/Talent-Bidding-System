## 用户管理模块

### 1. 用户注册
**路径**: `POST /api/v1/user_management/user_register`

**参数**:
```json
{
  "nickname": "用户昵称",
  "type": 1,
  "identityType": "email",
  "identifier": "user@example.com",
  "credential": "password123"
}
```

**参数说明**:
- `nickname`: 用户昵称
- `type`: 用户类型，1-学生，2-企业，3-管理员
- `identityType`: 认证类型，如email、phone
- `identifier`: 认证标识，如邮箱地址、手机号
- `credential`: 认证凭证，如密码

**返回示例**:
```json
{
  "code": "0000",
  "info": "成功",
  "data": true
}
```

### 2. 用户登录
**路径**: `POST /api/v1/user_management/user_login`

**参数**:
```json
{
  "identityType": "email",
  "identifier": "user@example.com",
  "credential": "password123"
}
```

**参数说明**:
- `identityType`: 认证类型
- `identifier`: 认证标识
- `credential`: 认证凭证

**返回示例**:
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "userId": "1234567890",
    "type": 1,
    "nickname": "张三",
    "avatarUrl": "http://example.com/avatar.jpg",
    "authentication": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

### 3. 创建管理员账号
**路径**: `POST /api/v1/user_management/admin/create_admin`

**参数**:
```json
{
  "nickname": "管理员",
  "identityType": "email",
  "identifier": "admin@example.com",
  "credential": "admin123"
}
```

### 4. 更新用户资料
**路径**: `POST /api/v1/user_management/update_profile`

**参数**:
```json
{
  "nickname": "新昵称",
  "avatarUrl": "http://example.com/new-avatar.jpg",
  "bio": "个人简介",
  "gender": "male",
  "birthday": "1990-01-01",
  "regionCode": "110000",
  "industry": "互联网",
  "title": "工程师"
}
```

## 项目管理模块

### 1. 创建项目
**路径**: `POST /api/v1/project/create_project`

**参数**:
```json
{
  "title": "项目标题",
  "description": "项目描述",
  "categoryId": "分类ID",
  "tags": "Java,Spring,MySQL",
  "requirements": "项目需求说明",
  "skillLevel": "intermediate",
  "teamSizeMin": 3,
  "teamSizeMax": 5,
  "durationDays": 90,
  "budgetType": "fixed",
  "budgetAmount": 50000.00,
  "currency": "CNY",
  "applicationDeadline": "2025-04-01T00:00:00",
  "expectedStartDate": "2025-04-15T00:00:00",
  "expectedEndDate": "2025-07-15T00:00:00"
}
```

**参数说明**:
- `title`: 项目标题
- `description`: 项目描述
- `categoryId`: 项目分类ID
- `tags`: 项目标签，逗号分隔
- `requirements`: 项目需求
- `skillLevel`: 技能水平要求，如beginner、intermediate、advanced
- `teamSizeMin`: 最小团队人数
- `teamSizeMax`: 最大团队人数
- `durationDays`: 项目持续天数
- `budgetType`: 预算类型，fixed-固定总价、hourly-按时计费、negotiable-面议
- `budgetAmount`: 预算金额
- `currency`: 货币类型，如CNY、USD
- `applicationDeadline`: 申请截止时间
- `expectedStartDate`: 预期开始时间
- `expectedEndDate`: 预期结束时间

### 2. 保存项目草稿
**路径**: `POST /api/v1/project/save_draft`

**参数**: 同创建项目

### 3. 更新项目
**路径**: `POST /api/v1/project/update_project`

**参数**:
```json
{
  "projectId": "项目ID",
  "title": "更新后的标题",
  "description": "更新后的描述"
}
```

### 4. 查询项目详情
**路径**: `GET /api/v1/project/detail/{projectId}`

**返回示例**:
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "projectId": "1234567890",
    "serialNumber": "PRJ20250301001",
    "title": "项目标题",
    "description": "项目描述",
    "status": "published",
    "budgetAmount": 50000.00,
    "currency": "CNY",
    "publisherId": "企业ID",
    "acceptedTeamId": "团队ID",
    "applicationCount": 5,
    "viewCount": 100
  }
}
```

### 5. 查询我的项目列表
**路径**: `GET /api/v1/project/my_projects`

**参数**:
- `status`: 项目状态（可选）
- `pageNum`: 页码，默认1
- `pageSize`: 每页数量，默认10

### 6. 提交项目审核
**路径**: `POST /api/v1/project/submit_review/{projectId}`

### 6.1 直接发布草稿（跳过审核）

**请求头**: 需要企业令牌（Bearer Token）

**路径**: `GET /api/v1/project/published`

**参数**:
- `categoryId`: 分类ID（可选）
- `pageNum`: 页码，默认1
- `pageSize`: 每页数量，默认10

**路径**: `POST /api/v1/project/search`

**参数**:

**路径**: `GET /api/v1/project/popular`

**参数**:
- `limit`: 数量限制，默认10

### 10. 获取最新项目
**路径**: `GET /api/v1/project/latest`

**参数**:
- `limit`: 数量限制，默认10

### 11. 管理员-获取待审核项目

**参数**:
- `pageNum`: 页码，默认1

### 12. 管理员-审核通过项目
**路径**: `POST /api/v1/project/admin/approve/{projectId}`

### 13. 管理员-拒绝项目
**路径**: `POST /api/v1/project/admin/reject`

**参数**:
```json
{
  "projectId": "项目ID",

}
```

### 14. 创建项目分类
**路径**: `POST /api/v1/project/admin/category/create`

**参数**:

```json
{
  "name": "分类名称",
  "parentId": "父分类ID",
  "description": "分类描述",
  "icon": "图标URL",
  "sortOrder": 1
```

### 15. 更新项目分类

**参数**:

**路径**: `GET /api/v1/project/category/{categoryId}`

## 竞榜管理模块

### 1. 申请竞榜
**路径**: `POST /api/v1/bid/apply`

**参数**:
```json
{
  "projectId": "项目ID",
  "content": "申请说明",
  "attachmentUrl": "附件URL"
}
```

**参数说明**:
- `projectId`: 要竞榜的项目ID
- `content`: 申请说明内容
- `attachmentUrl`: 附件URL（可选）

### 2. 查询项目的竞榜列表
**路径**: `GET /api/v1/bid/project/{projectId}`

**参数**:
- `status`: 竞榜状态（可选），applied、shortlisted、confirmed、rejected、cancelled
- `pageNum`: 页码，默认1
- `pageSize`: 每页数量，默认10

**返回示例**:
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "bids": [
      {
        "bidId": "2022959748642639872",
        "projectId": "2022959380340805632",
        "teamId": "2020476698205753344",
        "status": "applied",
        "content": "擅长Java后端与MySQL调优，近期完成过校园实验室排班系统。",
        "attachmentUrl": "https://resume.example.com/student-001.pdf",
        "remark": null,
        "createdAt": "2026-02-15T17:02:44",
        "updatedAt": "2026-02-15T17:02:44"
      }
    ],
    "total": 1,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

**返回字段说明**:
- `bidId`: 竞榜记录ID
- `projectId`: 项目ID
- `teamId`: 申请团队ID（可通过 `/team/detail/{teamId}` 查询团队详情）
- `status`: 竞榜状态（小写），applied/shortlisted/confirmed/rejected/cancelled
- `content`: 申请说明
- `attachmentUrl`: 附件URL
- `remark`: 审核备注
- `createdAt`: 创建时间
- `updatedAt`: 更新时间

### 3. 入围竞榜
**路径**: `POST /api/v1/bid/shortlist`

**参数**:
```json
{
  "bidId": "竞榜ID",
  "remark": "审核备注（可选）"
}
```

### 4. 确认竞榜
**路径**: `POST /api/v1/bid/confirm`

**参数**:
```json
{
  "bidId": "竞榜ID",
  "remark": "确认备注（可选）"
}
```

### 5. 拒绝竞榜
**路径**: `POST /api/v1/bid/reject`

**参数**:
```json
{
  "bidId": "竞榜ID",
  "remark": "拒绝原因"
}
```

### 6. 取消竞榜
**路径**: `POST /api/v1/bid/cancel/{bidId}`

```json
      {
```

- `projectId`: 项目ID

**参数**:
```json
{
  "milestoneId": "里程碑ID",
  "deliverableUrl": "成果文件URL"
}
```

### 5. 提交里程碑成果（文件上传）
**路径**: `POST /api/v1/milestone/deliverable/upload`

**Content-Type**: `multipart/form-data`

**参数**:
- `milestoneId`: 里程碑ID（表单字段）
- `file`: 成果文件（文件字段）

### 6. 审批里程碑
**路径**: `POST /api/v1/milestone/approve`

**参数**:
```json
{
  "milestoneId": "里程碑ID",
  "approved": true,
  "remark": "审批意见"
}
```

**参数说明**:
- `milestoneId`: 里程碑ID
- `approved`: 是否通过，true-通过，false-拒绝
- `remark`: 审批意见

### 7. 更新里程碑状态
**路径**: `POST /api/v1/milestone/status`

**参数**:
```json
{
  "milestoneId": "里程碑ID",
  "status": "in_progress"
}
```

**参数说明**:
- `status`: 状态值，planned、in_progress、delivered、under_review、completed、rejected、expired、skipped

### 8. 更新里程碑信息
**路径**: `POST /api/v1/milestone/update`

**参数**:

```json
  "milestoneId": "里程碑ID",
  "description": "新描述",
  "plannedStartTime": "2025-04-01T00:00:00",
  "plannedEndTime": "2025-04-15T00:00:00",
  "remindBeforeHours": 24
```

### 9. 跳过里程碑

## 业务固定取值

### 用户类型 (type)
- `1`: 学生
- `2`: 企业
- `3`: 管理员

### 项目状态 (status)
- `draft`: 草稿
- `pending_review`: 待审核
- `rejected`: 已拒绝
- `published`: 已发布
- `in_progress`: 进行中
- `completed`: 已完成
- `closed`: 已关闭

### 预算类型 (budgetType)
- `fixed`: 固定总价
- `hourly`: 按时计费
- `negotiable`: 面议

### 里程碑编码 (milestoneCode)
- `proposal_submission`: 方案提交
- `mid_term_defense`: 中期答辩
- `deliverable_submission`: 成果提交
- `result_review`: 成果评审
- `project_settlement`: 项目结算
- `closure_announcement`: 结项公示

### 里程碑状态 (status)
- `planned`: 计划中
- `in_progress`: 进行中
- `delivered`: 已交付
- `under_review`: 评审中
- `completed`: 已完成
- `rejected`: 已拒绝
- `expired`: 已过期
- `skipped`: 已跳过

### 里程碑审批状态 (approvalStatus)
- `pending`: 待审批
- `partial`: 部分审批
- `approved`: 已审批
- `rejected`: 已拒绝

### 竞榜状态 (status)
- `applied`: 已申请
- `shortlisted`: 已入围
- `confirmed`: 已确认
- `rejected`: 已拒绝
- `cancelled`: 已取消
- `expired`: 已过期

### 团队状态 (status)
- `active`: 活跃
- `inactive`: 不活跃
- `disbanded`: 已解散
