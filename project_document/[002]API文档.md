## 用户管理模块

### 1. 用户注册

**说明**：所有用户类型（学生/企业）通用注册接口

**路径**：`POST /api/v1/user_management/user_register`

**请求体**：
```json
{
  "nickname": "张三",
  "type": 1,
  "identityType": "email",
  "identifier": "user@example.com",
  "credential": "password123"
}
```

**请求参数说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | String | 是 | 用户昵称 |
| type | Integer | 是 | 用户类型：1-学生，2-企业，3-管理员（注册仅允许1/2） |
| identityType | String | 是 | 认证类型，如 `email`、`phone` |
| identifier | String | 是 | 认证标识，如邮箱地址、手机号 |
| credential | String | 是 | 认证凭证（密码） |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": true
}
```

### 2. 用户登录（含管理员）

**说明**：所有用户类型（学生/企业/管理员）通用登录接口，返回 JWT Token

**路径**：`POST /api/v1/user_management/user_login`

**请求体**：
```json
{
  "identityType": "email",
  "identifier": "user@example.com",
  "credential": "password123"
}
```

**请求参数说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| identityType | String | 是 | 认证类型，如 `email`、`phone` |
| identifier | String | 是 | 认证标识 |
| credential | String | 是 | 密码 |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "userId": "2018608120762339328",
    "type": "1",
    "nickname": "张三",
    "avatarUrl": "http://example.com/avatar.jpg",
    "userAuthCredentialId": "xxx",
    "identityType": "email",
    "identifier": "user@example.com",
    "credential": "加密后的密码",
    "isActive": 1,
    "isVerified": 1,
    "verifyTime": "2026-01-01T10:00:00",
    "lastLoginTime": "2026-03-10T10:00:00",
    "authentication": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

**返回字段说明**：
| 字段 | 说明 |
|------|------|
| authentication | JWT Token，后续请求放入 Authorization 头 |
| type | 用户类型字符串："1"-学生，"2"-企业，"3"-管理员 |
| isActive | 账号状态：1-激活，2-禁用 |

### 7. 企业上传资质文件

**说明**：企业上传资质文件，支持多次上传，每次上传的文件会自动追加到文件列表中（需企业用户登录）

**路径**：`POST /api/v1/user_management/company/upload_qualification`

**请求格式**：`multipart/form-data`

**请求参数**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 资质文件（支持格式：pdf,doc,docx,jpg,jpeg,png,zip,rar，最大10MB） |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": "/static/qualifications/123456/business_license.jpg"
}
```

**说明**：
- 返回的文件URL可以直接访问下载
- 企业可以多次上传，每次上传返回新的文件URL
- 所有上传的文件信息会自动保存在企业资料的 `qualificationFiles` 字段中（JSON数组格式）
- 文件信息包括：fileName（文件名）、fileUrl（访问URL）、fileSize（文件大小）、uploadTime（上传时间）

**文件列表格式示例**：
```json
[
  {
    "fileName": "营业执照.jpg",
    "fileUrl": "/static/qualifications/123456/营业执照.jpg",
    "fileSize": 102400,
    "uploadTime": "2026-03-13T10:00:00"
  },
  {
    "fileName": "资质证书.pdf",
    "fileUrl": "/static/qualifications/123456/资质证书.pdf",
    "fileSize": 204800,
    "uploadTime": "2026-03-13T10:05:00"
  }
]
```

### 9. 管理员查询企业列表（可选状态筛选）

| page | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页数量，默认 10 |

**返回字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| total | Long | 总记录数 |
| list[].userId | String | 用户ID |
| list[].companyName | String | 企业名称 |
| list[].creditCode | String | 统一社会信用代码 |
| list[].companyIndustry | String | 行业领域 |
| list[].certificationStatus | String | 认证状态 |
| list[].updateTime | String | 更新时间 |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "total": 5,

      {
```

## 项目管理模块

### 1. 企业创建项目（直接提交审核）

**说明**：企业创建项目并直接提交审核，状态变为 `pending_review`

**路径**：`POST /api/v1/project/create_project`

**请求体**：
```json
{
  "title": "校园门户系统升级",
  "description": "项目详细描述...",
  "categoryId": "分类ID",
  "tags": "Java,Spring,MySQL",
  "requirements": "需要有Spring Boot开发经验",
  "skillLevel": "intermediate",
  "teamSizeMin": 3,
  "teamSizeMax": 5,
  "durationDays": 90,
  "budgetType": "fixed",
  "budgetAmount": 50000.00,
  "currency": "CNY",
  "applicationDeadline": "2026-04-01T00:00:00",
  "expectedStartDate": "2026-04-15",
  "expectedEndDate": "2026-07-15"
}
```

**请求参数说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | String | 是 | 项目标题 |
| description | String | 是 | 项目描述 |
| categoryId | String | 否 | 项目分类ID |
| tags | String | 否 | 标签，逗号分隔 |
| requirements | String | 否 | 特殊要求 |
| skillLevel | String | 否 | 技能等级：`beginner`/`intermediate`/`advanced` |
| teamSizeMin | Integer | 否 | 团队最小人数 |
| teamSizeMax | Integer | 否 | 团队最大人数 |
| durationDays | Integer | 否 | 项目持续天数 |
| budgetType | String | 否 | 预算类型：`fixed`/`hourly`/`negotiable` |
| budgetAmount | BigDecimal | 否 | 预算金额 |
| currency | String | 否 | 货币，默认 `CNY` |
| applicationDeadline | LocalDateTime | 否 | 申请截止时间，格式 `yyyy-MM-ddTHH:mm:ss` |
| expectedStartDate | LocalDate | 否 | 预计开始日期，格式 `yyyy-MM-dd` |
| expectedEndDate | LocalDate | 否 | 预计结束日期，格式 `yyyy-MM-dd` |

**返回示例**：
```json
{ "code": "0000", "info": "成功", "data": true }
```

### 2. 企业保存项目草稿

**说明**：企业保存项目为草稿状态（`draft`），不提交审核

**路径**：`POST /api/v1/project/save_draft`

**前置条件**：企业必须已通过资质认证（`certification_status` 为 `certified`），未认证企业调用将被拒绝。

**请求体**：同创建项目，所有字段均可选

## 业务固定取值

### 项目状态（status）
| 值 | 说明 |
|----|------|
| draft | 草稿 |
| pending_review | 待审核 |
| published | 已发布 |
| rejected | 已拒绝 |
| in_progress | 进行中 |
| completed | 已完成 |
| cancelled | 已取消 |

### 揭榜状态（bid status）
| 值 | 说明 |
|----|------|
| pending | 待审核 |
| shortlisted | 已入围 |
| confirmed | 已中标 |
| rejected | 已拒绝 |
| cancelled | 已取消 |

### 里程碑状态（milestone status）
| 值 | 说明 |
|----|------|
| planned | 计划中 |
| in_progress | 进行中 |
| delivered | 已交付 |
| under_review | 评审中 |
| completed | 已完成 |
| rejected | 已拒绝 |
| expired | 已过期 |
| skipped | 已跳过 |

**状态流转逻辑**：

```
planned → in_progress → delivered → under_review → completed
                                         ↓
                                     rejected
                                         ↓
                                   in_progress（重新提交）
```

**状态流转说明**：

1. **planned → in_progress**：里程碑开始执行（手动更新状态）
2. **in_progress → delivered**：学生提交里程碑交付物（调用提交接口）
3. **delivered → under_review**：企业开始评审（手动更新状态）
4. **under_review → completed**：企业审核通过（调用审核接口）
5. **under_review → rejected**：企业审核拒绝（调用审核接口）
6. **rejected → in_progress**：学生重新提交（手动更新状态）

**特殊状态**：
- **expired**：里程碑已过期（超过截止时间未完成，系统自动标记或手动设置）
- **skipped**：里程碑已跳过（手动跳过某个里程碑）

### 用户类型（type）
| 值 | 说明 |
|----|------|
| 1 | 学生 |
| 2 | 企业 |
| 3 | 管理员 |
