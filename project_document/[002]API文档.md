# 产教融合揭榜挂帅系统 API 文档

## 概述

本系统是一个产教融合揭榜挂帅平台，为企业和学生提供项目合作机会。系统采用分层架构设计，包含用户管理、项目管理、团队管理、投标管理和里程碑管理等核心功能模块。

**API 版本**: v1
**基础URL**: `http://localhost:8080` (开发环境) `http://43.142.157.145:8091`(测试环境)，现在要求直接使用测试环境url
**认证方式**: JWT Token (通过请求头 `Authorization` 传递)
**数据格式**: JSON
**字符编码**: UTF-8

## 通用响应格式

所有API响应都遵循统一的格式：

```json
{
  "code": 200,
  "info": "success",
  "data": {}
}
```

### 响应字段说明
- `code`: 响应码，200表示成功
- `info`: 响应信息
- `data`: 响应数据，内容根据具体接口而定

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未授权 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 1. 用户管理 API

**基础路径**: `/api/v1/user_management`

### 1.1 用户注册

**接口**: `POST /api/v1/user_management/user_register`

**描述**: 新用户注册账号

**请求参数**:
```json
{
  "nickname": "用户昵称",
  "type": "用户类型 (STUDENT/ENTERPRISE/ADMIN)",
  "identityType": "认证类型 (USERNAME/EMAIL/PHONE)",
  "identifier": "唯一标识符",
  "credential": "凭证/密码"
}
```

**响应**:
```json
{
  "code": 200,
  "info": "success",
  "data": true
}
```

### 1.2 用户登录

**接口**: `POST /api/v1/user_management/user_login`

**描述**: 用户登录获取认证令牌

**请求参数**:
```json
{
  "identityType": "认证类型",
  "identifier": "唯一标识符",
  "credential": "凭证/密码"
}
```

**响应**:
```json
{
  "code": 200,
  "info": "success",
  "data": {
    "userId": "用户ID",
    "type": "用户类型",
    "nickname": "用户昵称",
    "avatarUrl": "头像URL",
    "userAuthCredentialId": "认证凭证ID",
    "identityType": "认证类型",
    "identifier": "唯一标识符",
    "isActive": true,
    "isVerified": true,
    "verifyTime": "验证时间",
    "lastLoginTime": "最后登录时间",
    "authentication": "JWT令牌"
  }
}
```

### 1.3 创建管理员账号

**接口**: `POST /api/v1/user_management/admin/create_admin`

**描述**: 管理员创建新的管理员账号

**权限**: 仅管理员

**请求参数**:
```json
{
  "nickname": "管理员昵称",
  "identityType": "认证类型",
  "identifier": "唯一标识符",
  "credential": "凭证/密码"
}
```

### 1.4 更新用户资料

**接口**: `POST /api/v1/user_management/update_profile`

**描述**: 更新当前用户的个人资料

**权限**: 已登录用户


## 认证和授权

### JWT Token 使用

1. 用户登录成功后，会在响应中获得 `authentication` 字段，即JWT令牌
2. 后续请求需要在HTTP请求头中添加：`Authorization: Bearer {token}`
3. Token有效期为24小时，过期后需要重新登录

### 用户角色权限

- **学生(STUDENT)**: 可以浏览项目、投标、创建团队、提交里程碑成果
- **企业(ENTERPRISE)**: 可以创建项目、管理项目、审批投标、审批里程碑
- **管理员(ADMIN)**: 可以管理用户、审核项目、管理分类、创建管理员账号

## 数据验证规则

### 通用验证规则

- 字符串字段不能为空白字符
- 邮箱格式验证
- 手机号格式验证
- 密码长度至少6位
- 数字字段范围验证

### 业务验证规则

- 项目预算金额必须大于0
- 团队成员数量必须在合理范围内
- 里程碑截止时间不能早于当前时间
- 投标金额不能超过项目预算

## 错误处理

系统采用统一的错误处理机制，所有异常都会被转换为标准响应格式：

```json
{
  "code": 400,
  "info": "参数错误：用户昵称不能为空",
  "data": null
}
```

## 分页查询

支持分页的接口使用以下参数：

- `pageNum`: 页码，从1开始
- `pageSize`: 每页记录数，默认10，最大100

分页响应格式：

```json
{
  "code": 200,
  "info": "success",
  "data": {
    "list": [...],
    "total": 100,
    "pageNum": 1,
    "pageSize": 10,
    "pages": 10
  }
}
```

## 文件上传

系统支持文件上传功能，主要用于：

- 项目附件上传
- 里程碑成果提交
- 用户头像上传

文件上传接口返回文件访问URL，前端可直接使用该URL显示或下载文件。
