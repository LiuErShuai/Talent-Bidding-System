## 一、总览

### 1.1 页面结构

企业项目管理页面包含4个子页面：

| 子页面 | 组件文件 | 功能说明 |
|--------|---------|---------|
| 基本信息 | BiddingBasicInfo.vue | 展示项目基本信息、揭榜统计、当前里程碑 |
| 揭榜管理 | BiddingManagement.vue | 管理揭榜申请、审核团队、查看团队资料 |
| 里程碑详情 | MilestoneDetail.vue | 查看里程碑详情、管理任务文件、查看提交记录 |
| 历史记录 | HistoryRecords.vue | 查看所有文件上传记录 |

### 1.2 API汇总表

#### 需要补充字段的API

| API | 所属页面 | 缺少字段 | 优先级 |
|-----|---------|---------|--------|
| `GET /api/v1/project/detail/{projectId}` | 基本信息 | publisherName, biddingStats | P0 |
| `GET /api/v1/bid/project/{projectId}` | 揭榜管理 | team, attachments, reviewHistory | P0 |
| `POST /api/v1/bid/reject` | 揭榜管理 | remark参数 | P1 |
| `GET /api/v1/milestone/{milestoneId}` | 里程碑详情 | ~~deliverables~~, taskFiles, submissions, ~~feedbacks~~（删除线部分为V2.0功能） | P0 |

#### 需要补充的API

| API | 所属页面 | 作用 | 优先级 | 版本 |
|-----|---------|------|--------|------|
| `GET /api/v1/project/manage/{projectId}` | 基本信息 | 一次性获取项目管理所需数据 | P0 | V1.0 |
| `GET /api/v1/milestone/{milestoneId}/detail` | 里程碑详情 | 获取里程碑完整详细信息 | P0 | V1.0 |
| `POST /api/v1/milestone/{milestoneId}/task_file` | 里程碑详情 | 企业上传任务文件 | P1 | V1.0 |
| `GET /api/v1/milestone/{milestoneId}/task_files` | 里程碑详情 | 查询任务文件列表 | P1 | V1.0 |
| `DELETE /api/v1/milestone/task_file/{fileId}` | 里程碑详情 | 删除任务文件 | P1 | **V1.0优先级不高** |
| `GET /api/v1/milestone/{milestoneId}/submissions` | 里程碑详情 | 查询提交记录 | P1 | V1.0 |
| ~~`POST /api/v1/milestone/{milestoneId}/feedback`~~ | 里程碑详情 | 添加意见反馈 | P1 | **V2.0** |
| ~~`GET /api/v1/milestone/{milestoneId}/feedbacks`~~ | 里程碑详情 | 查询反馈意见 | P1 | **V2.0** |
| `GET /api/v1/project/{projectId}/file_history` | 历史记录 | 查询所有文件上传记录 | P1 | V1.0 |

## 二、基本信息页面API需求

### 2.1 页面需要的信息

**组件**：`src/components/enterprise/BiddingBasicInfo.vue`

**需要展示**：
1. 项目基本信息：名称、状态、发布时间、周期、描述、发布方企业名称
2. 揭榜统计：申请团队数、审核通过数、待审核数、中标团队名称
3. 当前里程碑：标题、状态、计划完成日期、交付物数量

### 2.2 需要补充字段的API

#### GET /api/v1/project/detail/{projectId}

**原始API返回**：只有 `publisherId`、`applicationCount`、`acceptedTeamId`

**缺少字段**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `publisherName` | String | 发布方企业名称 |
| `biddingStats.totalApplications` | Integer | 申请团队总数 |
| `biddingStats.approvedApplications` | Integer | 审核通过数 |
| `biddingStats.pendingApplications` | Integer | 待审核数 |
| `biddingStats.selectedTeamName` | String | 中标团队名称 |

### 2.3 需要补充的API

## 五、历史记录页面API需求

> ⚠️ **优先级说明**：历史记录页面优先级较低，建议先实现其他页面的功能

### 5.1 页面需要的信息

**组件**：`src/components/enterprise/HistoryRecords.vue`

**需要展示**：
1. 所有文件上传记录：文件名、大小、上传时间、上传人、所属里程碑
2. 支持分页浏览
3. 支持文件下载

### 5.2 需要补充的API

#### GET /api/v1/project/{projectId}/file_history

**作用**：统一查询项目的所有文件上传记录（揭榜申请文件+里程碑提交文件+任务文件）

**请求参数**：

| 参数名 | 类型 | 必选 | 说明 |
|--------|------|------|------|
| milestoneId | String | 否 | 按里程碑筛选 |
| fileType | String | 否 | 文件类型（bid_attachment/submission/task_file） |
| pageNum | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页数量，默认10 |

**返回字段**：

```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "files": [
      {
        "fileId": "f1",
        "fileName": "技术方案-v2.pdf",
        "fileUrl": "https://...",
        "fileSize": 3251200,
        "fileSizeFormatted": "3.1 MB",
        "uploadTime": "2025-11-18T14:30:00",
        "uploaderName": "张三",
        "uploaderType": "student",
        "fileType": "submission",
        "fileTypeText": "里程碑提交",
        "milestoneId": "m1",
        "milestoneName": "方案提交",
        "versionNote": "补充了技术选型依据"
      }
    ],
    "total": 3,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `fileName` | String | 文件名 |
| `fileUrl` | String | 文件下载URL |
| `fileSize` | Integer | 文件大小（字节） |
| `fileSizeFormatted` | String | 格式化后的文件大小（如"3.1 MB"） |
| `uploaderName` | String | 上传人姓名 |
| `uploaderType` | String | 上传人类型（student/enterprise） |
| `fileType` | String | 文件类型（bid_attachment/submission/task_file） |
| `fileTypeText` | String | 文件类型文本 |
| `milestoneName` | String | 所属里程碑名称 |

**文件类型说明**：

| fileType | fileTypeText | 说明 |
|----------|-------------|------|
| `bid_attachment` | 揭榜申请 | 学生提交揭榜申请时上传的附件 |
| `submission` | 里程碑提交 | 学生在里程碑提交的交付物 |
| `task_file` | 任务文件 | 企业为里程碑上传的参考资料 |

## 附录：开发优先级建议

### P0（高优先级 - 必须实现）
1. `GET /api/v1/project/manage/{projectId}` - 基本信息页面核心数据
2. `GET /api/v1/milestone/{milestoneId}/detail` - 里程碑详情核心数据
3. 补充 `GET /api/v1/project/detail/{projectId}` 的缺失字段
4. 补充 `GET /api/v1/bid/project/{projectId}` 的缺失字段

### P1（中优先级 - 建议实现）
1. `POST /api/v1/milestone/{milestoneId}/task_file` - 任务文件上传
2. `GET /api/v1/milestone/{milestoneId}/task_files` - 任务文件列表
3. `GET /api/v1/milestone/{milestoneId}/submissions` - 提交记录查询
4. `GET /api/v1/project/{projectId}/file_history` - 历史记录查询

### P2（低优先级 - 可延后实现）
1. `DELETE /api/v1/milestone/task_file/{fileId}` - 删除任务文件

### V2.0（后续版本）
1. `POST /api/v1/milestone/{milestoneId}/feedback` - 添加意见反馈
