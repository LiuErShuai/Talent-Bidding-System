## 维护说明

### 如何添加新问题

1. **确定所属模块**：判断问题属于哪个模块（学生揭榜、管理员审核等）
2. **在对应章节下追加**：在对应模块的"待记录问题"下追加具体问题
3. **问题格式**：参考 [003-1] 的问题格式，包含优先级、问题描述、影响、建议修改等
4. **更新主文档**：在主文档 [003] 的"问题优先级总览"中添加新问题

### 如何添加新模块

1. **在本文档中新增章节**：按照现有模块的格式添加新模块章节
2. **更新主文档**：在主文档 [003] 的"模块概览"中添加新模块说明
3. **考虑独立文档**：如果某个模块的问题较多（超过5个），考虑创建独立的子文档 `[003-5]`、`[003-6]` 等
