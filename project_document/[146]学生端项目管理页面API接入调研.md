## 缺失字段与问题分析

### 严重缺失（P0 - 阻塞功能）

#### 1. 团队成员信息（project.members）

**影响**：ProjectOverview组件无法显示团队成员列表

**现状**：
- Mock数据包含完整的团队成员信息（姓名、头像、角色、技能）
- API返回的项目详情中只有 `acceptedTeamId` 和 `acceptedTeamName`

**解决方案**：
- **方案A**：新增接口 `GET /api/v1/team/{teamId}/members` 获取团队成员详情
- **方案B**：项目详情接口扩展返回团队成员信息
- **临时方案**：隐藏团队成员展示，仅显示团队名称

#### 2. 里程碑交付物要求（milestone.deliverables）

**影响**：MilestoneDetailPanel无法显示交付物要求列表

**现状**：
- Mock数据包含详细的交付物要求（名称、类型、格式、具体要求）
- API返回的里程碑信息中没有交付物要求字段

**解决方案**：
- **方案A**：里程碑详情接口扩展 `deliverables` 数组字段
- **方案B**：新增接口 `GET /api/v1/milestone/{milestoneId}/deliverables`
- **临时方案**：在里程碑描述中说明交付物要求

#### 3. 里程碑任务文件（milestone.taskFiles）

**影响**：无法显示企业提供的参考资料和任务文件

**现状**：
- Mock数据包含企业上传的任务文件列表
- API返回的里程碑信息中没有任务文件字段

**解决方案**：
- **方案A**：里程碑详情接口扩展 `taskFiles` 数组字段
- **方案B**：新增接口 `GET /api/v1/milestone/{milestoneId}/task_files`
- **临时方案**：暂不显示任务文件区块

#### 4. 学生提交记录（milestone.submissions）

**影响**：无法显示学生的历史提交记录和审核结果

**现状**：
- Mock数据包含完整的提交记录（文件信息、版本说明、审核结果）
- API返回的里程碑信息中只有 `deliverableUrl`（单个URL）

**解决方案**：
- **方案A**：新增接口 `GET /api/v1/milestone/{milestoneId}/submissions` 获取提交历史
- **方案B**：里程碑详情接口扩展 `submissions` 数组字段
- **临时方案**：仅显示最新提交的URL链接

### 次要缺失（P1 - 影响体验）

#### 5. 项目分类名称（project.category）

**影响**：显示分类ID而非分类名称

**解决方案**：
- 前端维护分类ID到名称的映射表
- 或调用分类列表接口获取映射关系

#### 6. 里程碑延期天数（milestone.delayDays）

**影响**：无法直观显示延期情况

**解决方案**：
- 前端根据 `plannedEndTime` 和当前日期计算

### 数据格式问题

#### 7. 时间格式转换

**问题**：API返回ISO 8601格式（`2026-04-01T00:00:00`），Mock使用简单日期格式（`2025-11-01`）

**解决方案**：
- 前端统一使用工具函数转换时间格式
- 建议使用 `dayjs` 或 `date-fns` 库

## 接入方案设计

### 方案概述

基于当前API能力和缺失字段分析，采用**分阶段接入策略**：

**阶段一（核心功能）**：对接项目详情和里程碑列表接口，实现基础数据展示
**阶段二（完善功能）**：等待后端补充缺失接口后，完善交付物、提交记录等功能

### 阶段一：核心功能接入

#### 1. 数据加载流程

```javascript
async function fetchManageData() {
  loading.value = true
  try {
    // 并发请求项目详情和里程碑列表
    const [projectRes, milestonesRes] = await Promise.all([
      getProjectDetailAPI(projectId),
      getMilestonesByProjectAPI(projectId)
    ])

    // 数据映射
    project.value = mapProjectData(projectRes.data)
    milestones.value = mapMilestonesData(milestonesRes.data.milestones)

    // 自动选中当前进行中的里程碑
    selectCurrentMilestone()
  } catch (error) {
    ElMessage.error('加载项目数据失败')
    // 降级到Mock数据
    const data = mockProjectManageData
    project.value = data.project
    milestones.value = data.milestones
  } finally {
    loading.value = false
  }
}
```

```javascript
    endDate: formatDate(item.plannedEndTime),
    plannedDate: formatDate(item.plannedEndTime),
    actualDate: item.actualEndTime ? formatDate(item.actualEndTime) : null,
    delayDays: calculateDelayDays(item.plannedEndTime, item.actualEndTime),

    // 暂时使用空数组，等待后端补充接口
    deliverables: [],
    taskFiles: [],
    submissions: []
  }))
}

function mapMilestoneStatus(apiStatus) {
  const map = {
    'planned': 'pending',
    'in_progress': 'in-progress',
    'delivered': 'in-progress',
    'under_review': 'in-progress',
    'completed': 'completed',
    'rejected': 'skipped',
    'expired': 'skipped',
    'skipped': 'skipped'
  }
  return map[apiStatus] || 'pending'
}

function calculateDelayDays(plannedEndTime, actualEndTime) {
  if (!plannedEndTime) return 0
  const planned = new Date(plannedEndTime)
  const actual = actualEndTime ? new Date(actualEndTime) : new Date()
  const diff = actual - planned
  return diff > 0 ? Math.ceil(diff / (1000 * 60 * 60 * 24)) : 0
}
```

### 步骤3：修改页面数据加载逻辑（40分钟）

修改 `src/views/project/Manage/index.vue` 的 `fetchManageData` 函数：

```javascript
import { getProjectDetailAPI, getMilestonesByProjectAPI } from '@/api/project'
import { mapProjectData, mapMilestoneData } from '@/utils/projectMapper'

async function fetchManageData() {
  loading.value = true
  try {
    // 并发请求项目详情和里程碑列表
    const [projectResult, milestonesResult] = await Promise.allSettled([
      getProjectDetailAPI(projectId),
      getMilestonesByProjectAPI(projectId)
    ])

    // 处理项目详情
    if (projectResult.status === 'fulfilled') {
      project.value = mapProjectData(projectResult.value.data)
    } else {
      throw new Error('加载项目详情失败')
    }

    // 处理里程碑列表
    if (milestonesResult.status === 'fulfilled') {
      const milestonesData = milestonesResult.value.data.milestones || []
      milestones.value = milestonesData.map(mapMilestoneData)
    } else {
      milestones.value = []
    }

    // 自动选中当前进行中的里程碑
    const currentMilestone = milestones.value.find(m => m.status === 'in-progress')
    if (currentMilestone) {
      const index = milestones.value.findIndex(m => m.id === currentMilestone.id)
      selectedMilestone.value = currentMilestone
      selectedMilestoneIndex.value = index
    } else if (milestones.value.length > 0) {
      selectedMilestone.value = milestones.value[0]
      selectedMilestoneIndex.value = 0
    }

    console.log('项目数据加载成功：', {
      项目名称: project.value.name,
      里程碑数量: milestones.value.length
    })
  } catch (error) {
    ElMessage.error('加载项目数据失败，已切换为默认数据')
    console.error(error)

    // 降级到Mock数据
    const data = mockProjectManageData
    project.value = data.project
    milestones.value = data.milestones
  } finally {
    loading.value = false
  }
}
```
