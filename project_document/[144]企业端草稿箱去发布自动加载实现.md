# [144]企业端草稿箱去发布自动加载实现.md

## 背景与目标
企业端 `/enterprise/my-projects` 页面草稿箱中的“去发布”按钮原行为仅切换到发布页，未自动加载对应草稿数据，导致用户无法继续编辑历史草稿。

目标：点击“去发布”后，自动回填该草稿的项目信息与里程碑信息，并进入发布流程第1步继续编辑。

## 目录
1. 现状问题
2. 实现方案
3. TODOLIST
4. 实施结果

## 1. 现状问题
- 草稿箱卡片按钮点击事件为 `activeTab = 'publish'`，没有传入草稿上下文。
- 发布表单默认空白，用户无法直接续写草稿。

## 2. 实现方案
- 将草稿箱“去发布”按钮改为调用 `handlePublishDraft(project)`。
- 新增草稿加载方法：
  - 调用 `getProjectDetailAPI(project.id)` 回填步骤一表单字段。
  - 调用 `getAllMilestoneTemplatesAPI` + `getOptionalMilestoneTemplatesAPI` 生成前端里程碑结构。
  - 调用 `getMilestonesByProjectAPI(project.id)` 回填已启用里程碑及计划时间。
- 加载成功后：
  - 设置 `currentProjectId` 为当前草稿项目ID。
  - 切换到发布页并停留在步骤一（`currentStep = 0`）。
