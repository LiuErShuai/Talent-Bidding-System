## 📦 模块概览

### 1. 企业发布项目模块

**涉及文档**：
- [003-1]企业发布项目模块API问题与建议.md
- [003-2]企业发布项目API重新设计方案.md

**核心问题**：
- 现有 API 返回值不完整（save_draft 不返回 projectId）
- 里程碑模板缺失（协议签订）
- 批量操作接口缺失（里程碑期限批量更新）
- 字段缺失（goal、deliverables）
- 通用文件上传接口缺失

**设计方案**：
- 方案一：分步保存（8 个 API）
- 方案二：一次性提交（6 个 API）

**状态**：
- P0 问题 1 个（阻塞性）
- P1 问题 2 个（重要）
- P2 问题 2 个（后续版本）

---

### 2. 企业审核揭榜团队模块

**涉及文档**：
- [003-3]企业审核揭榜团队模块API设计.md

**核心问题**：
- 申请列表接口返回字段不足（缺少团队信息）
- 缺少申请详情接口
- 缺少揭榜统计接口
- 拒绝申请接口参数缺失

**设计方案**：
- 增强现有接口（申请列表、拒绝申请）
- 新增 3 个接口（申请详情、揭榜统计）

**状态**：
- P1 问题 3 个（重要）
- P2 问题 1 个（优化）
