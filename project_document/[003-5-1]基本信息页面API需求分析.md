## 页面需要的信息

**组件**：`src/components/enterprise/BiddingBasicInfo.vue`

**需要展示**：
1. 项目基本信息：名称、状态、发布时间、周期、描述、发布方企业名称
2. 揭榜统计：申请团队数、审核通过数、待审核数、中标团队名称
3. 当前里程碑：标题、状态、计划完成日期、交付物数量

---

## 需要补充字段的API

### GET /api/v1/project/detail/{projectId}

**原始API返回**：只有 `publisherId`、`applicationCount`、`acceptedTeamId`

**缺少字段**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `publisherName` | String | 发布方企业名称 |
| `biddingStats.totalApplications` | Integer | 申请团队总数 |
| `biddingStats.approvedApplications` | Integer | 审核通过数 |
| `biddingStats.pendingApplications` | Integer | 待审核数 |
| `biddingStats.selectedTeamName` | String | 中标团队名称 |

## 需要补充的API

### GET /api/v1/project/manage/{projectId}

**作用**：一次性获取项目管理页面所需数据（项目信息+揭榜统计+当前里程碑）

**请求参数**：

| 参数名 | 位置 | 类型 | 必选 | 说明 |
|--------|------|------|------|------|
| projectId | path | String | 是 | 项目ID |
| Authorization | header | String | 是 | 认证token |

**返回字段**：

```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "projectId": "xxx",
    "title": "项目名称",
    "description": "项目描述",
    "status": "in-progress",
    "publishedAt": "2025-10-19T16:00:00",
    "expectedStartDate": "2025-12-01",
    "expectedEndDate": "2026-01-30",
    "publisher": {
      "publisherId": "xxx",
      "publisherName": "桂林电子科技大学科技有限公司"
    },
    "biddingStats": {
      "totalApplications": 4,
      "approvedApplications": 2,
      "pendingApplications": 1,
      "rejectedApplications": 1,
      "selectedTeamId": "xxx",
      "selectedTeamName": "创新科技团队"
    },
    "currentMilestone": {
      "milestoneId": "xxx",
      "name": "方案提交",
      "status": "in-progress",
      "plannedEndTime": "2025-11-20T23:59:59",
      "deliverableCount": 2
    }
  }
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `publisher.publisherName` | String | 发布方企业名称 |
| `biddingStats.totalApplications` | Integer | 申请团队总数 |
| `biddingStats.approvedApplications` | Integer | 审核通过数 |
| `biddingStats.pendingApplications` | Integer | 待审核数 |
| `biddingStats.selectedTeamName` | String | 中标团队名称 |
| `currentMilestone.name` | String | 当前里程碑名称 |
| `currentMilestone.status` | String | 里程碑状态 |
| `currentMilestone.plannedEndTime` | String | 计划完成时间 |
| `currentMilestone.deliverableCount` | Integer | 交付物数量 |
