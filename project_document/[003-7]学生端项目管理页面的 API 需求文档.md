## 一、总览

### 1.1 页面结构

学生端项目管理页面是学生查看和管理项目里程碑的核心页面，包含以下核心组件：

| 组件名称 | 组件文件 | 功能说明 |
|---------|---------|---------|
| 项目概览 | ProjectOverview.vue | 展示项目基本信息、团队成员、揭榜统计 |
| 里程碑进度条 | MilestoneProgressBar.vue | 可视化展示所有里程碑的进度和状态 |
| 里程碑详情面板 | MilestoneDetailPanel.vue | 展示里程碑详情、任务文件、提交记录 |

**页面布局**：
- 顶部：固定导航栏（面包屑导航）
- 主体：单栏布局
  - 项目概览卡片
  - 里程碑进度条
  - 里程碑详情面板（3个标签页：基本信息、任务文件、提交文件）

### 1.2 业务流程图

```
用户访问 /projects/:id/manage
    ↓
调用 GET /api/v1/project/detail/{projectId}
    ↓ 获取项目基本信息
    ↓
调用 GET /api/v1/milestone/project/{projectId}
    ↓ 获取里程碑列表
    ↓
自动选中进行中的里程碑（或第一个里程碑）
    ↓
调用 GET /api/v1/milestone/{milestoneId}
    ↓ 获取里程碑详情 + 任务文件 + 提交记录
    ↓
展示页面内容
```

**用户交互流程**：
1. **切换里程碑**：点击进度条节点 → 调用里程碑详情API → 更新详情面板
2. **上传交付物**：点击"上传交付物"按钮 → 选择文件 + 填写描述信息（可选） → 调用上传API → 刷新里程碑详情
3. **下载文件**：点击下载按钮 → 调用文件下载API → 浏览器下载文件

## 三、需要补充的API

### 3.1 任务文件查询

#### GET /api/v1/milestone/{milestoneId}/task_files

**作用**：查询任务文件列表（企业上传的参考资料）

**请求参数**：

| 参数名 | 位置 | 类型 | 必选 | 说明 |
|--------|------|------|------|------|
| milestoneId | path | String | 是 | 里程碑ID |
| Authorization | header | String | 是 | 认证token |

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": [
    {
      "id": "task-file-3",
      "name": "技术方案编写指南.pdf",

      "uploader": "XX科技有限公司",
      "description": "技术方案文档的编写规范和要求"
    }
  ]
}
```

### 3.3 文件上传

#### POST /api/v1/milestone/{milestoneId}/submission

**作用**：上传交付物（支持描述信息）

**请求参数**：

| 参数名 | 位置 | 类型 | 必选 | 说明 |
|--------|------|------|------|------|
| milestoneId | path | String | 是 | 里程碑ID |
| file | body | File | 是 | 上传的文件 |
| description | body | String | 否 | 描述信息（最多500字） |
| Authorization | header | String | 是 | 认证token |

**请求格式**：`multipart/form-data`

**请求示例**：
```http
POST /api/v1/milestone/milestone-proposal/submission
Content-Type: multipart/form-data
Authorization: Bearer xxx

file: [文件二进制数据]
description: "根据上次审核意见进行了全面修改"
```

**返回示例**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "submissionId": "3",
    "fileName": "技术方案-AI智能客服系统.pdf",
    "fileSize": "3.1 MB",
    "uploadTime": "2025-11-18 14:30"
  }
}
```

**业务逻辑**：
1. 文件上传到云存储（OSS/S3）
2. 创建提交记录
3. 返回提交记录基本信息

**错误处理**：

| 错误码 | 说明 |
|--------|------|
| `ERR_FILE_001` | 文件大小超过限制（500MB） |
| `ERR_FILE_002` | 文件格式不支持 |
| `ERR_MILESTONE_001` | 里程碑不存在 |
| `ERR_MILESTONE_002` | 里程碑状态不允许提交 |

### 3.4 文件下载

#### GET /api/v1/file/download/{fileId}

**作用**：获取文件下载链接或直接下载文件

**请求参数**：

| 参数名 | 位置 | 类型 | 必选 | 说明 |
|--------|------|------|------|------|
| fileId | path | String | 是 | 文件ID |
| Authorization | header | String | 是 | 认证token |

**返回方式1：返回下载链接**

```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "fileId": "task-file-3",
    "fileName": "技术方案编写指南.pdf",
    "downloadUrl": "https://oss.example.com/files/xxx?expires=3600&signature=xxx",
    "expiresIn": 3600
  }
}
```

**返回方式2：直接重定向**

```http
HTTP/1.1 302 Found
Location: https://oss.example.com/files/xxx?expires=3600&signature=xxx
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| `downloadUrl` | 临时下载链接（有效期1小时） |
| `expiresIn` | 链接有效期（秒） |

**建议实现**：
- 使用云存储的临时签名URL（如阿里云OSS、腾讯云COS）
- 设置合理的过期时间（建议1小时）
- 支持断点续传

#### P0（高优先级 - 必须实现）

#### P1（中优先级 - 建议实现）

这些API是重要功能，建议尽快实现：

1. **POST /api/v1/milestone/{milestoneId}/submission**
   - 作用：上传交付物（支持描述信息）
   - 影响：学生无法提交作业

2. **GET /api/v1/file/download/{fileId}**
   - 作用：下载文件
   - 影响：无法下载任务文件和提交记录

3. **GET /api/v1/milestone/{milestoneId}/task_files**
   - 作用：查询任务文件列表
   - 影响：可以通过里程碑详情接口获取，但单独接口更灵活

4. **GET /api/v1/milestone/{milestoneId}/submissions**
   - 作用：查询提交记录列表
   - 影响：可以通过里程碑详情接口获取，但单独接口更灵活
