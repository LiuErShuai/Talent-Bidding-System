# 企业创建项目完整流程文档

## 一、流程概述

企业创建项目的完整流程包括：保存草稿 → 配置里程碑 → 提交审核 → 管理员审核 → 项目发布

本文档详细描述从创建草稿到提交审核的前端API调用流程。

---

## 二、项目状态流转

```
draft（草稿）
  ↓ 提交审核
pending_review（待审核）
  ↓ 审核通过          ↓ 审核拒绝
published（已发布）  rejected（已拒绝）
  ↓                    ↓ 可重新提交审核
in_progress（进行中）
  ↓
completed（已完成）
  ↓
closed（已关闭）
```

---

## 三、API调用流程

### 步骤1：保存项目草稿

**接口**: `POST /api/v1/project/save_draft`

**请求头**:
```
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体**:
```json
{
  "title": "智能物流管理系统开发",
  "description": "开发一套完整的智能物流管理系统，包括订单管理、仓储管理、配送管理等模块",

  "requirements": "1. 熟悉Java开发\n2. 有前端开发经验\n3. 了解物流业务",
  "skillLevel": "intermediate",
  "teamSizeMin": 3,
  "teamSizeMax": 5,
  "durationDays": 90,
  "budgetType": "fixed",

  "expectedStartDate": "2025-03-15T00:00:00",
  "expectedEndDate": "2025-06-15T00:00:00"
```

**响应示例**:

**说明**:

- 返回的响应中可以从日志或后续查询中获取 `projectId`

### 步骤3：更新每个里程碑的信息

**接口**: `POST /api/v1/milestone/update`

**请求头**:
```
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体**:
```json
{
  "milestoneId": "1234567890",
  "description": "团队需要提交完整的项目实施方案，包括技术架构、开发计划、人员分工等内容",
  "plannedStartTime": "2025-03-15T00:00:00",
  "plannedEndTime": "2025-03-30T23:59:59",
  "remindBeforeHours": 24
}
```

**响应示例**:
```json
{
  "code": "0000",
  "info": "成功",
  "data": true
}
```

**说明**:
- 需要为每个里程碑调用此接口
- `description` 必填：里程碑的详细描述
- `plannedStartTime` 必填：计划开始时间
- `plannedEndTime` 必填：计划结束时间
- `remindBeforeHours` 可选：提前多少小时提醒，默认24小时

**前端实现示例**:
```javascript
// 循环更新所有里程碑
for (const milestone of milestones) {
  await updateMilestone({
    milestoneId: milestone.milestoneId,
    description: formData[`milestone_${milestone.milestoneCode}_desc`],
    plannedStartTime: formData[`milestone_${milestone.milestoneCode}_start`],
    plannedEndTime: formData[`milestone_${milestone.milestoneCode}_end`],
    remindBeforeHours: 24
  });
}
```

### 步骤6：提交审核

**接口**: `POST /api/v1/project/submit_review/{projectId}`

**请求头**:
```
Authorization: Bearer {token}
```

**响应示例（成功）**:
```json
{
  "code": "0000",
  "info": "成功",
  "data": true
}
```

**响应示例（失败 - 未配置里程碑）**:
```json
{
  "code": "ERR_BIZ_054",
  "info": "项目尚未配置里程碑，无法提交审核",
  "data": false
}
```

**响应示例（失败 - 里程碑信息不完整）**:
```json
{
  "code": "ERR_BIZ_055",
  "info": "里程碑【方案提交】缺少描述信息",
  "data": false
}
```

**后端校验逻辑**:
1. 检查项目是否存在
2. 检查操作权限（只有项目发布者可以提交）
3. 检查项目状态（只有 `draft` 或 `rejected` 状态可以提交）
4. **检查是否配置了里程碑**
5. **检查每个里程碑的描述是否填写**
6. **检查每个里程碑的计划时间是否设置**

**说明**:
- 提交成功后，项目状态变为 `pending_review`
- 如果校验失败，前端需要根据错误信息提示用户完善相应内容

## 四、完整前端实现示例

```javascript
class ProjectCreationService {
  
  /**
   * 完整的项目创建流程
   */
  async createProjectWithMilestones(projectData, milestonesData) {
    try {
      // 1. 保存草稿
      const projectId = await this.saveDraft(projectData);
      console.log('项目草稿保存成功，项目ID:', projectId);
      
      // 2. 获取里程碑列表
      const milestones = await this.getMilestones(projectId);
      console.log('获取到里程碑列表，共', milestones.length, '个');
      
      // 3. 更新每个里程碑
      for (const milestone of milestones) {
        const milestoneData = milestonesData[milestone.milestoneCode];
        if (milestoneData) {
          await this.updateMilestone({
            milestoneId: milestone.milestoneId,
            description: milestoneData.description,
            plannedStartTime: milestoneData.startTime,
            plannedEndTime: milestoneData.endTime,
            remindBeforeHours: milestoneData.remindHours || 24
          });
          console.log('里程碑更新成功:', milestone.name);
        }
      }
      
      // 4. 可选：添加额外的里程碑
      if (milestonesData.optionalTemplateIds?.length > 0) {
        await this.addOptionalMilestones(projectId, milestonesData.optionalTemplateIds);
        console.log('可选里程碑添加成功');
        
        // 更新新增的里程碑信息
        const updatedMilestones = await this.getMilestones(projectId);
        for (const milestone of updatedMilestones) {
          if (milestonesData[milestone.milestoneCode]) {
            await this.updateMilestone({
              milestoneId: milestone.milestoneId,
              ...milestonesData[milestone.milestoneCode]
            });
          }
        }
      }
      
      // 5. 提交审核
      await this.submitForReview(projectId);
      console.log('项目提交审核成功');
      
      return { success: true, projectId };
      
    } catch (error) {
      console.error('项目创建流程失败:', error);
      return { success: false, error: error.message };
    }
  }
  
  async saveDraft(projectData) {
    const response = await fetch('/api/v1/project/save_draft', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.getToken()}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(projectData)
    });
    const result = await response.json();
    if (result.code !== '0000') {
      throw new Error(result.info);
    }
    return projectData.projectId; // 需要从响应或其他方式获取
  }
  
  async getMilestones(projectId) {
    const response = await fetch(`/api/v1/milestone/project/${projectId}`, {
      headers: {
        'Authorization': `Bearer ${this.getToken()}`
      }
    });
    const result = await response.json();
    if (result.code !== '0000') {
      throw new Error(result.info);
    }
    return result.data.milestones;
  }
  
  async updateMilestone(milestoneData) {
    const response = await fetch('/api/v1/milestone/update', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.getToken()}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(milestoneData)
    });
    const result = await response.json();
    if (result.code !== '0000') {
      throw new Error(result.info);
    }
    return result.data;
  }
  
  async addOptionalMilestones(projectId, templateIds) {
    const response = await fetch('/api/v1/milestone/template/create', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.getToken()}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ projectId, templateIds })
    });
    const result = await response.json();
    if (result.code !== '0000') {
      throw new Error(result.info);
    }
    return result.data;
  }
  
  async submitForReview(projectId) {
    const response = await fetch(`/api/v1/project/submit_review/${projectId}`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.getToken()}`
      }
    });
    const result = await response.json();
    if (result.code !== '0000') {
      throw new Error(result.info);
    }
    return result.data;
  }
  
  getToken() {
    return localStorage.getItem('token');
  }
}

// 使用示例
const service = new ProjectCreationService();

const projectData = {
  title: "智能物流管理系统开发",
  description: "开发一套完整的智能物流管理系统",
  categoryId: "CAT_001",
  // ... 其他字段
};

const milestonesData = {
  proposal_submission: {
    description: "团队需要提交完整的项目实施方案",
    startTime: "2025-03-15T00:00:00",
    endTime: "2025-03-30T23:59:59",
    remindHours: 24
  },
  mid_term_defense: {
    description: "项目中期进度汇报和答辩",
    startTime: "2025-04-15T00:00:00",
    endTime: "2025-04-20T23:59:59",
    remindHours: 48
  },
  // ... 其他里程碑
};

service.createProjectWithMilestones(projectData, milestonesData)
  .then(result => {
    if (result.success) {
      console.log('项目创建成功！');
    } else {
      console.error('项目创建失败:', result.error);
    }
  });
```

## 五、错误码说明

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| ERR_BIZ_054 | 项目尚未配置里程碑，无法提交审核 | 确保已调用里程碑初始化接口 |
| ERR_BIZ_055 | 里程碑信息不完整 | 检查所有里程碑的描述和时间是否填写完整 |
| ERR_BIZ_013 | 项目不存在 | 检查项目ID是否正确 |
| ERR_BIZ_015 | 无权限操作该项目 | 只有项目发布者可以提交审核 |
| ERR_BIZ_016 | 项目状态不允许此操作 | 只有草稿或被拒绝的项目可以提交审核 |

## 六、注意事项

1. **里程碑必填项**：每个里程碑的描述、计划开始时间、计划结束时间都是必填的
2. **时间合理性**：计划结束时间必须晚于计划开始时间
3. **权限控制**：只有项目发布者本人可以更新项目和提交审核
4. **状态限制**：只有 `draft` 或 `rejected` 状态的项目可以提交审核
5. **草稿自动初始化**：保存草稿后会自动初始化必须的里程碑，无需手动创建
6. **可选里程碑**：企业可以根据项目需要添加额外的可选里程碑

---

## 七、后续流程

提交审核后，项目进入管理员审核环节：

1. **管理员审核通过**: `POST /api/v1/project/admin/approve/{projectId}`
   - 项目状态变为 `published`（已发布）
   - 学生可以看到并申请该项目

2. **管理员审核拒绝**: `POST /api/v1/project/admin/reject`
   - 项目状态变为 `rejected`（已拒绝）
   - 企业可以修改后重新提交审核

| final_defense | 最终答辩 | 项目最终成果展示 |
| project_acceptance | 项目验收 | 企业对项目进行验收 |
| payment_settlement | 款项结算 | 项目款项结算 |
| project_closure | 项目结项 | 项目正式结束 |

| 编码 | 名称 | 说明 |
|------|------|------|
| technical_review | 技术评审 | 对技术方案进行评审 |
