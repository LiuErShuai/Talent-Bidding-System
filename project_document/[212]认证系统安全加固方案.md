# [212] 认证系统安全加固方案

## 背景与目标

### 背景
在代码审查过程中发现认证系统存在以下安全隐患：
1. **路由守卫覆盖不全**：部分页面（项目大厅、项目详情、关于我们、隐私政策）未设置认证要求，导致未登录用户可以访问
2. **缺少无操作超时机制**：用户登录后，即使长时间不操作，token 也不会过期，存在安全风险
3. **Token 无有效期检查**：前端未对 token 的有效期进行校验，只依赖后端返回 401
4. **退出登录不彻底**：退出时未清理 sessionStorage 和旧的 localStorage key

### 目标
1. 确保除首页及其导航栏页面（合作企业、关注我们、帮助中心）外，所有页面都需要登录才能访问
2. 实现 30 分钟无操作自动退出机制，提前 1 分钟警告用户
3. 增加 token 最大有效期检查（24 小时），应用启动时自动校验
4. 完善退出登录逻辑，确保所有认证信息被彻底清除

## 问题分析

### 问题一：路由守卫覆盖不全

**当前状态：**
以下路由的 `requiresAuth` 设置为 `false`，允许未登录用户访问：
- `/projects` - 项目大厅
- `/projects/:id` - 项目详情
- `/about` - 关于我们
- `/privacy` - 隐私政策

**期望状态：**
根据需求，只有以下页面允许未登录访问：
- `/home` - 首页
- `/partners` - 合作企业
- `/contact` - 关注我们（联系我们）
- `/help` - 帮助中心

其他所有页面都需要登录。

### 问题二：缺少无操作超时机制

**当前状态：**
- Token 存储在 localStorage，永久有效
- 只有后端返回 401 时才会清除 token
- 用户可以长时间保持登录状态，即使不操作

**安全风险：**
- 用户离开电脑后，他人可以直接使用已登录的账号
- 公共场所使用后忘记退出，账号安全无法保障

### 问题三：Token 无有效期检查

**当前状态：**
- `initAuth()` 只检查 token 和 userInfo 是否存在
- 不检查 token 是否过期
- 用户关闭浏览器一周后再打开，仍然是登录状态

**安全风险：**
- Token 可能已在后端失效，但前端仍认为已登录
- 导致用户访问页面时才发现需要重新登录，体验不佳

### 问题四：退出登录不彻底

**当前状态：**
- `logout()` 只清除 token、userInfo、userRole
- 未清除 sessionStorage 中的 `pendingAuthDialog`
- 未清除旧的 localStorage key（如 `userData`）

**潜在问题：**
- 残留数据可能导致状态不一致
- 重新登录时可能触发意外的弹窗行为

## 解决方案

### 方案一：修改路由守卫配置

**文件：** `src/router/modules/common.js`

**修改内容：**
将以下路由的 `requiresAuth` 改为 `true`：
- `/projects` → `requiresAuth: true`
- `/projects/:id` → `requiresAuth: true`
- `/about` → `requiresAuth: true`
- `/privacy` → `requiresAuth: true`

同时移除 `isPublicPage: true` 标记。

### 方案二：实现无操作自动退出

**文件：** `src/composables/useInactivityTimeout.js`（新建）

**功能设计：**
1. 监听用户活动事件：`mousemove`、`keydown`、`click`、`scroll`、`touchstart`
2. 每次活动重置计时器
3. 30 分钟无操作后自动登出
4. 登出前 1 分钟弹出警告通知
5. 只在已登录状态下生效

**集成位置：** `src/layouts/DefaultLayout.vue`

### 方案三：增加 Token 有效期检查

**文件：** `src/store/modules/auth.js`

**修改内容：**
1. 在 `state` 中增加 `loginTime` 字段，记录登录时间戳
2. `login()` 时保存当前时间戳到 localStorage
3. `initAuth()` 时检查是否超过 24 小时，超过则自动登出
4. `logout()` 时清除 `loginTime`

### 方案四：完善退出登录逻辑

**文件：** `src/store/modules/auth.js`

**修改内容：**
1. 清除 `loginTime`
2. 清除 sessionStorage 中的 `pendingAuthDialog`
3. 清除旧的 localStorage key（`userData`）

### 2. 创建无操作超时组合式函数

```javascript
// src/composables/useInactivityTimeout.js

import { ref, onMounted, onUnmounted } from 'vue'
import { useAuthStore } from '@/store/modules/auth'
import { useRouter } from 'vue-router'
import { ElMessageBox, ElNotification } from 'element-plus'

const DEFAULT_TIMEOUT = 30 * 60 * 1000 // 30分钟
const WARNING_TIME = 1 * 60 * 1000 // 提前1分钟警告

export function useInactivityTimeout(options = {}) {
  const {
    timeout = DEFAULT_TIMEOUT,
    warningTime = WARNING_TIME,
    enabled = true
  } = options

  const authStore = useAuthStore()
  const router = useRouter()

  let inactivityTimer = null
  let warningTimer = null
  let warningShown = false

  // 重置计时器
  const resetTimer = () => {
    if (!enabled || !authStore.isLoggedIn) return

    clearTimeout(inactivityTimer)
    clearTimeout(warningTimer)
    warningShown = false

    // 警告计时器
    warningTimer = setTimeout(() => {
      if (!warningShown && authStore.isLoggedIn) {
        warningShown = true
        showWarning()
      }
    }, timeout - warningTime)

    // 自动登出计时器
    inactivityTimer = setTimeout(() => {
      if (authStore.isLoggedIn) {
        handleAutoLogout()
      }
    }, timeout)
  }

  // 显示警告
  const showWarning = () => {
    ElNotification({
      title: '会话即将过期',
      message: '您已经1分钟没有操作了，系统将在1分钟后自动退出登录。移动鼠标或点击页面可继续使用。',
      type: 'warning',
      duration: 10000,
      position: 'top-right'
    })
  }

  // 自动登出
  const handleAutoLogout = () => {
    ElMessageBox.alert(
      '由于长时间未操作，系统已自动退出登录，请重新登录。',
      '会话已过期',
      {
        confirmButtonText: '确定',
        type: 'warning',
        showClose: false,
        callback: () => {
          authStore.logout()
          router.push('/home')
          setTimeout(() => {
            window.dispatchEvent(
              new CustomEvent('open-auth-dialog', {
                detail: { mode: 'login', redirect: '' }
              })
            )
          }, 300)
        }
      }
    )
  }

  // 启动监听
  const startListening = () => {
    if (!enabled) return

    const events = ['mousemove', 'keydown', 'click', 'scroll', 'touchstart']
    events.forEach(event => {
      window.addEventListener(event, resetTimer, { passive: true })
    })

    resetTimer()
  }

  // 停止监听
  const stopListening = () => {
    const events = ['mousemove', 'keydown', 'click', 'scroll', 'touchstart']
    events.forEach(event => {
      window.removeEventListener(event, resetTimer)
    })

    clearTimeout(inactivityTimer)
    clearTimeout(warningTimer)
  }

  onMounted(() => startListening())
  onUnmounted(() => stopListening())

  return { resetTimer, startListening, stopListening }
}
```

### 4. 增强认证状态管理

```javascript
// src/store/modules/auth.js

export const useAuthStore = defineStore('auth', {
  state: () => ({
    token: local.get(STORAGE_KEYS.TOKEN) || '',
    userInfo: local.get(STORAGE_KEYS.USER_INFO) || {},
    userRole: local.get(STORAGE_KEYS.USER_ROLE) || '',
    isLoggedIn: false,
    loginTime: local.get('loginTime') || null // 新增：登录时间戳
  }),

  actions: {
    // 登录时记录时间戳
    login(userData, token) {
      const now = Date.now()

      this.token = token
      this.userInfo = userData
      this.userRole = userData.role || userData.type?.toLowerCase() || ''
      this.isLoggedIn = true
      this.loginTime = now

      local.set(STORAGE_KEYS.TOKEN, token)
      local.set(STORAGE_KEYS.USER_INFO, userData)
      local.set(STORAGE_KEYS.USER_ROLE, this.userRole)
      local.set('loginTime', now) // 保存登录时间
    },

    // 完善退出逻辑
    logout() {
      this.token = ''
      this.userInfo = {}
      this.userRole = ''
      this.isLoggedIn = false
      this.loginTime = null

      // 清除所有存储
      local.remove(STORAGE_KEYS.TOKEN)
      local.remove(STORAGE_KEYS.USER_INFO)
      local.remove(STORAGE_KEYS.USER_ROLE)
      local.remove('loginTime')

      // 清除旧 key
      localStorage.removeItem('userData')

      // 清除 sessionStorage
      try {
        sessionStorage.removeItem('pendingAuthDialog')
      } catch {
        // 忽略错误
      }
    },

    // 初始化时检查 token 有效期
    initAuth() {
      let token = local.get(STORAGE_KEYS.TOKEN)
      let userInfo = local.get(STORAGE_KEYS.USER_INFO)
      let userRole = local.get(STORAGE_KEYS.USER_ROLE)
      let loginTime = local.get('loginTime')

      // 兼容旧存储方式...（省略）

      if (token && userInfo) {
        // 检查 token 是否过期（24小时）
        const MAX_TOKEN_AGE = 24 * 60 * 60 * 1000
        const now = Date.now()

        if (loginTime && (now - loginTime > MAX_TOKEN_AGE)) {
          console.warn('Token 已过期，需要重新登录')
          this.logout()
          this.isLoggedIn = false
        } else {
          // Token 有效，恢复登录状态
          this.token = token
          this.userInfo = userInfo
          this.userRole = userRole
          this.loginTime = loginTime
          this.isLoggedIn = true
        }
      } else {
        this.isLoggedIn = false
      }
    }
  }
})
```

## 注意事项

1. **无操作超时只在 DefaultLayout 中生效**：如果有其他布局（如 AdminLayout），需要单独集成
2. **警告通知可能被用户忽略**：建议在警告时使用更明显的提示方式
3. **Token 有效期与后端不一致**：前端设置的 24 小时只是前端校验，后端可能有不同的过期时间
4. **多标签页问题**：当前实现在每个标签页独立计时，可能导致一个标签页退出后其他标签页仍然登录
5. **移动端兼容性**：已添加 `touchstart` 事件监听，但需要在移动设备上测试

---

## 后续优化建议

1. **跨标签页同步**：使用 `BroadcastChannel` 或 `localStorage` 事件实现多标签页的登录状态同步
2. **Token 刷新机制**：实现 refresh token，避免用户在使用过程中突然退出
3. **记住我功能**：允许用户选择延长登录有效期
4. **活动日志**：记录用户的活动时间，用于安全审计
5. **更智能的超时策略**：根据用户行为模式动态调整超时时间
