# [138] 登录注册 API 接入方案

## 1. 概述

本文档描述前端接入后端登录注册 API 的实现方案。目标是在保留"选择角色便捷登录"测试模式的同时，接入真实的后端 API 进行账密验证。

**接入范围**：仅学生端和企业端（暂不包含教师和管理员）

## 2. 后端 API 信息

**基础 URL**：`http://43.142.157.145:8091`（测试环境）

### 2.1 注册接口

```
POST /api/v1/user_management/user_register
```

**请求参数**：
```json
{
  "nickname": "用户昵称",
  "type": "学生",              // 中文：学生/企业
  "identityType": "username",  // 小写：username/email/phone
  "identifier": "唯一标识符",
  "credential": "密码"
}
```

**响应格式**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": true
}
```

### 2.2 登录接口

```
POST /api/v1/user_management/user_login
```

**请求参数**：
```json
{
  "identityType": "username",  // 小写：username/email/phone
  "identifier": "用户名",
  "credential": "密码"
}
```

**响应格式**：
```json
{
  "code": "0000",
  "info": "成功",
  "data": {
    "userId": "用户ID",
    "type": "学生/企业",
    "nickname": "用户昵称",
    "avatarUrl": "头像URL",
    "authentication": "JWT令牌"
  }
}
```

## 3. 实现方案

### 3.1 预设测试账号

为保留便捷登录功能，需要预先注册以下测试账号：

| 角色 | 用户名 | 密码 | type |
|------|--------|------|------|
| 学生 | `test_student` | `Test123456` | 学生 |
| 企业 | `test_enterprise` | `Test123456` | 企业 |

**创建命令**（使用 Apifox 或 curl）：

```bash
# 创建学生账号
curl -X POST "http://43.142.157.145:8091/api/v1/user_management/user_register" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"测试学生","type":"学生","identityType":"username","identifier":"test_student","credential":"Test123456"}'

# 创建企业账号
curl -X POST "http://43.142.157.145:8091/api/v1/user_management/user_register" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"测试企业","type":"企业","identityType":"username","identifier":"test_enterprise","credential":"Test123456"}'
```

### 3.3 关键代码

#### request.js 响应拦截器
```javascript
request.interceptors.response.use(
  (response) => {
    const res = response.data
    // 兼容 code 为 200 或 "0000" 的成功响应
    if (res.code !== 200 && res.code !== '0000') {
      ElMessage.error(res.info || res.message || '请求错误')
      return Promise.reject(res)
    }
    return res
  },
  // ...
)
```

## 4. 测试步骤

1. **创建测试账号**：使用 Apifox 调用注册接口创建 `test_student` 和 `test_enterprise` 账号
2. **启动前端**：`npm run dev`
3. **测试登录**：选择学生或企业角色，点击登录
4. **验证结果**：检查是否成功获取 token 并跳转

## 5. 注意事项

1. **参数格式**：
   - `type` 字段使用中文：`学生` / `企业`
   - `identityType` 字段使用小写：`username` / `email` / `phone`
   - 响应码是字符串 `"0000"`，不是数字 `200`

2. **密码要求**：至少 6 位，包含字母和数字
