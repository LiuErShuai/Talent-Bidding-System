# [143] 企业端创建项目三步骤 API 对接修复文档

## 背景与目标

`src/views/enterprise/MyProjects.vue` 已有三步骤创建项目的 API 调用代码，但存在 4 处数据结构解包错误，导致步骤一→步骤二跳转失败（里程碑列表无法加载）以及步骤三提交发布失败。

本次修复目标：修正这 4 处 bug，使整个三步骤流程能正确对接后端 API。

## 目录

1. 问题根因
2. 修复清单（TODOLIST）
3. 修复详情
4. 验证清单

## 1. 问题根因

`request.js` 响应拦截器返回 `response.data`，即调用方收到 `{ code, data, info }`。后端各接口的 `data` 字段均为嵌套对象（非直接数组），但代码中直接将 `res.data` 当数组使用，导致解包失败。

| 接口 | `res.data` 实际结构 |
|------|-------------------|
| `getMyProjectsAPI` | `{ projects: [...], total, pageNum, pageSize }` |
| `getAllMilestoneTemplatesAPI` | `{ templates: [...] }` |
| `getOptionalMilestoneTemplatesAPI` | `{ templates: [...] }` |
| `getMilestonesByProjectAPI` | `{ milestones: [...], total }` |

## 3. 修复详情

所有修改均在 `src/views/enterprise/MyProjects.vue`：

**修复 1**（步骤一，获取新建草稿的 projectId）：
```js
// 改前
const projList = projRes.data || []
// 改后
const projList = projRes.data?.projects || []
```

**修复 2 & 3**（步骤一，加载里程碑模板）：
```js
// 改前
const allTemplates = allRes.data || []
const optionalTemplates = optRes.data || []
// 改后
const allTemplates = allRes.data?.templates || []
const optionalTemplates = optRes.data?.templates || []
```

**修复 4**（步骤三，获取服务端里程碑以匹配 milestoneId）：
```js
// 改前
const serverMilestones = msRes.data || []
// 改后
const serverMilestones = msRes.data?.milestones || []
```
