## 页面需要的信息

**组件**：`src/components/enterprise/BiddingManagement.vue`

**需要展示**：
1. 申请列表：团队名称、负责人、团队人数、联系方式、申请时间、状态
2. 团队详细资料：多个文件（团队介绍、身份认证、技术方案等）
3. 审核历史记录：审核时间、审核动作、审核意见
4. 审核操作：通过、拒绝、选为中标（需要填写备注）

## 需要补充字段的API

### GET /api/v1/bid/project/{projectId}

**原始API返回**：只有 `studentId`、`teamId`、`attachmentUrl`（单个文件）

**缺少字段**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `team.teamName` | String | 团队名称 |
| `team.leaderName` | String | 负责人姓名 |
| `team.memberCount` | Integer | 团队人数 |
| `team.contact` | String | 联系方式 |
| `attachments` | Array | 多个附件文件列表 |
| `reviewHistory` | Array | 审核历史记录 |

**建议返回**：
```json
{
  "bids": [
    {
      "bidId": "xxx",
      "status": "APPLIED",
      "content": "申请说明",
      "createdAt": "2025-11-13T20:11:11",
      "team": {
        "teamName": "创新科技团队",
        "leaderName": "张三",
        "memberCount": 5,
        "contact": "13800138000"
      },
      "attachments": [
        {
          "fileId": "f1",
          "fileName": "团队介绍.pdf",
          "fileUrl": "https://...",
          "fileSize": 2411724
        }
      ],
      "reviewHistory": [
        {
          "reviewTime": "2025-11-02T14:00:00",
          "action": "SHORTLISTED",
          "comment": "团队资质符合要求"
        }
      ]
    }
  ]
}
```
